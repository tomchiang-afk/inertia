## Notes

- Tap coordinates were generated by replaying each flow in Chromium at the device's CSS viewport
  (411×838 @2.625, WebView top at 136 px), then sent as `adb shell input` commands.
- The emulator's saved data still carries the 5 TWD drift from step 13. JPY and HKD rates in its
  TWD table are 6-decimal-rounded values, not the typed defaults. This affects only this test
  device. The fix stops new drift but does not rewrite a table that has already drifted. Typing a
  rate (or clearing app data) resets it.
- Native `<select>` dialogs need 2 adb rounds: open, screenshot, then tap the option.
  Option order is the current base first, then the table order.
- 27-picker-list.png is the unfiltered picker (the search-box tap missed). 28 is the search result.
- The 2×2 widget's empty band between the header and net worth is out of scope here. The widget visual
  redesign (`design/widget-v3/`) handles it.
